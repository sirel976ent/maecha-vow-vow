## Format

- Résolution minimale : 752×1360 px
- Naming : `{EP}_{PLANCHE}.png` (ex : `1_00.png`, `3_07.png`)

## Règles Visuelles

| ✅ FAIRE | ❌ NE PAS FAIRE |
|----------|-----------------|
| Vêtements UNIS (plain solid) | Motifs floraux ou géométriques |
| Style manhwa semi-réaliste | Style réaliste photo |
| Lumière naturelle tropicale | Éclairage froid ou studio |
| Expressions nuancées | Expressions caricaturales |
| Format 9:16 strict | Autre format |
| Contenu implicite/symbolique | Scènes explicites |

## Décors Clés Mayotte

- **Kwassa-kwassa** : embarcation de nuit, mer sombre, horizon
- **Mamoudzou** : marché, rues, architecture coloniale + moderne
- **Banga** (maison traditionnelle) : intérieur simple, lit, fenêtre barreaudée
- **Marché Mamoudzou** : étals colorés, foule, lumière chaude
- **Centre d'accueil** : chambre simple, propre, fenêtre ouverte sur mer

## Contenu Sensible — Épisode 3

L'épisode 3 traite de l'exploitation sexuelle :
- **JAMAIS** de scène explicite, nudité ou violence graphique
- Utiliser : ellipses narratives, portes qui se ferment, ombres, silhouettes
- Focus sur les émotions de Maria (dissociation, vide) — pas sur les actes
- Symbolisme : miroir brisé, horloge, fenêtre barreaudée
