# STYLE GUIDE — Maecha VowVow

## Projet
- **Titre** : Maecha VowVow
- **Client** : PSP Mayotte (Prevention / Sensibilisation / Protection)
- **Format** : Webtoon vertical (scroll)
- **Theme** : Prevention cyberharcèlement et manipulation en ligne chez les jeunes a Mayotte
- **Public cible** : Adolescents 14-18 ans, Mayotte et Outre-mer

---

## Style Artistique

### Bloc style obligatoire (a inclure dans CHAQUE prompt)
```
Korean webtoon manhwa style, semi-realistic, soft cel-shading, clean thin black outlines, vertical format 9:16, high quality digital art
```

### Caracteristiques
- **Style** : Manhwa coreen (webtoon)
- **Rendu** : Semi-realiste
- **Ombrage** : Cel-shading doux et subtil
- **Contours** : Lignes noires fines et propres
- **Format** : Vertical 9:16 (1080x1920 minimum)

### Palette de couleurs recurrente
| Element | Couleurs |
|---------|----------|
| Ambiance positive | Tons chauds (orange, dore, rose coucher de soleil) |
| Ambiance negative | Tons froids (bleu nuit, gris, eclairage telephone) |
| Ambiance neutre | Lumiere naturelle tropicale (vert, bleu ciel, jaune soleil) |

### Ancrage local Mayotte
- Architecture : maisons en parpaings colorees, toits en tole, murs bleu clair
- Vegetation : baobabs, manguiers, palmiers, fleurs tropicales
- Ocean : turquoise, lagon, plages de sable blanc
- Ciel : couchers de soleil spectaculaires orange/rose/violet
- Interieur maison : canape en tissu colore, fenetres jalousies aluminium, photos de famille

## Regles de production

1. **Copier le bloc prompt** de chaque personnage depuis sa CHARACTER_SHEET — NE JAMAIS paraphraser
2. **Inclure le bloc [STYLE]** dans chaque prompt sans exception
3. **Format vertical 9:16** toujours specifie
4. **Verifier la continuite** avec les planches precedentes
5. **Pas de contenu explicite ou violent** — le sujet est traite avec sensibilite
